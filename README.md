# Scale AI x SpaceXAI

Passworded customer leave-behind for Scale AI.

## What it is

The page shows a Scale AI sales team working with a fleet of Grok Bot agents. The hero has eight example agent jobs and an interactive iOS phone demo. Three longer use cases show the work moving from a trigger to a review-ready artifact.

## Run locally

```bash
cp .env.example .env.local
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Set `SITE_PASSWORD` to `land2expand` for the shared review password.

## Stack

- Next.js 15.5
- React 19
- Geist
- vGPU telemetry
- Tailwind CSS 4

The Scale wordmark is the official mark described by the Scale 2.0 brand guidelines. Do not replace it with a Simple Icons asset.
